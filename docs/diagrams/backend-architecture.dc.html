Patient app
Chat for goals · symptom tap before and after exercise · “I feel unwell” on every screen.
Smartwatch
Apple Watch, Galaxy Watch, Garmin via HealthKit / Health Connect: heart rate, steps, workouts.
Clinician limit record
Named clinician signs: HR ceiling, effort target, activity types, source test, date, review-by.
Discharge note
Risk class, ICD, LVEF, beta-blocker flag, surgery date. Entered or scanned, then clinician-confirmed.
Consent & caregiver
PDPA consent per data use. Optional LINE summary for family. Insurer access off by default.
Symptom screen + red flag
Rules only. Every tap and typed message screened in Thai and English. Match or unclear: stop + emergency number [confirm 1669].
Health data bridge
Drop implausible heart rate [CLINICIAN range], dedupe, fix timezone. Stale data: safe default.
Limit-record gate
Rules only. No signed, current record: no exercise missions. Self-entered or expired: blocked.
Eligibility gate
Rules only. Unknown risk, ICD, low LVEF, unstable symptoms, recent surgery: refer. v1 = low-risk post-MI.
Patient state store
Limits, risk class, validated data, consent, check-ins, events. Agent reads limits, never writes them.
Coach agent (LLM, Claude)
Talks with the patient, agrees weekly goals, picks missions only from the allowed set. No limit writes, no drug advice.
MCP tool surface
Read: get_recent_activity · get_hr_summary · get_patient_limits (read-only)
Write: propose_week_plan (checked against allowed set) · schedule_notification · log_checkin (log only)
Mission engine
Rules only. Limits + validated data + risk class give the allowed mission set.
• Warm-up and cool-down in every mission
• Duration rises before intensity; weekly cap [CLINICIAN]
• Beta-blocker flag: effort rating + talk test, not heart rate alone
• No outdoor missions in midday heat
• No data or no record: no intensity increase
• Wants more? Request goes to the clinician
Output filter
Rules only. Blocks drug or dose advice, diagnosis wording and intensity above the limit. Fails closed.
Notification scheduler
One or two missions a day at the time the patient chooses. Missed days: easier mission, no streak or guilt wording.
Clinician flag queue
Limit-review requests, red-flag events, “I stopped my medicine”, missed doses. The agent never answers these itself.
Audit log + adherence
Every agent turn, tool call and safety event. Day-7 / day-28 active, completion, mute rate.
Today screen
One or two mission cards, symptom tap, Done. Stop screen on a red flag.
Phone push, mirrored to watch
Short, action-first text. Patient picks the time; not fixed at midday.
Clinician web
Review flags, set or renew limit records, release missions. Scope for v1 still open.
Weekly summary
One sentence a week. Optional LINE note for family (later).
