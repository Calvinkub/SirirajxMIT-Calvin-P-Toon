FAQ 03 · What runs inside the agent harness?

Open models hear, decide and speak; rules decide what is safe

HEAR

Qwen3-ASR 1.7B

Thai and English speech to text. Thai is a listed language. Apache-2.0, streams on vLLM.

DECIDE

MedGemma 27B

Picks a mission id from the allowed set and returns JSON. One turn, English input.

Qwen3-4B routes intents and calls MCP tools. MedGemma 1.5 4B reads discharge notes for a clinician to confirm.

SPEAK

Qwen3-TTS

English voice. Open weights lack Thai, so Thai uses Typhoon2-Audio or JaiTTS (to test). Thai text is fact-checked first.

Rules only, no LLM

Red-flag screen before any model · allowed mission set · output filter · safe default on any failure

Each model gets one narrow job with a typed input and output. MedGemma’s model card says it is not for direct clinical decisions, not tuned for multi-turn chat, and red-teamed mostly in English, so we give it one English JSON request and let it choose only from missions the rules allow. Qwen3-TTS open weights cover 10 languages and not Thai, which is why Thai speech out needs a second engine.
