Built on the InterSystems FHIR-AI Hackathon Kit (IRIS for Health with FHIR server, FHIR SQL Builder, Vector Search). Planned; the Heartstep UI exists today.

Every fact the agent uses is a standard FHIR R4 resource in IRIS for Health. The agents never touch the database directly: they read and write through typed MCP tools over FHIR. The rules engine reads FHIR SQL Builder tables. The clinician signs the limit record through a SMART on FHIR app (support to confirm on the IRIS FHIR Server). Hospital HL7v2 or CDA feeds are a later step.
